# circuitpy_tamagotchi -- *WORK IN PROGRESS!!!*
I am still working on making this. It should be done soon enough, please check back later. 
A tamagotchi clone made in circuit python. Not designed to be used again but I'll try to document it well so you can make it if you want to. This all assumes you have a basic knolage of soldering and programing with python.

## Hardware used
Most Items are listed with an amazon link and price but for most an alternitive would probably work, you may need to rewite some code of you change the board or display but I think anything else should work reletively seamlessly.  
[rp 2350 plus board](https://www.amazon.com/RP2350-MCU-Board-Plus-Dual-Architecture/dp/B0DP5XZY7B) - $12.47  
[240x240 Display](https://www.amazon.com/dp/B0GVFCF89S) - $8.99  
[1000mAh LiPo Battery](https://www.amazon.com/dp/B0FT3C1WRP) - $9.99 - if you dont get this one make sure you get one with a JST 1.25M connecter  
[Passive Buzzer](https://www.amazon.com/dp/B0GKNH6FPR) - $4.99 - this is the smallest pack I could find having 10 pieces, but you only need 1  
[Switch](https://www.amazon.com/dp/B0F83SHDK9) - $3.99 - this is the smallest pack I could find having 20 pieces, but you only need 1  
[PCB Board](https://www.amazon.com/dp/B0CBPRBRTT) - $7.29 - this is just to hold the buttons in place, again this is a 10 pack but you only need 1  
[Buttons](https://www.amazon.com/dp/B01GN79QF8) - out of stock when I went back to check so no price was listed - this is a 10 pack, you only need 3  

You also need a soldering station, thin wires (I used 24 AWG), and a 3D printer  
I may be missing something
